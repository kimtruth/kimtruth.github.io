Samsung CTF PreQuals 2017 - Asm (500 pts.)

2017-07-17
Samsung CTF PreQuals 2017

문제 요약

이미지를 보고 계산 결과를 보내주면 됐다.

또한, 100문제를 80초안에 해결해야 했으므로 자동화하는 것을 짜야했다.

문제 해결 과정

  1. 먼저 색상을 기준으로 분리한다.

red.png

green.png

purple.png

  1. red.png, green.png, purple.png에서 숫자를 하나하나 분리하는데 파일 이름을 x좌표로 한다.

  1. 분리된 숫자들을 기반으로 각각의 기준이 되는 이미지를 정한다.

  2. 기준이 되는 이미지와 width, height를 비교하여 무슨 숫자인지 판별 가능하다.

  3. [0, 8, 6, 9], [3, 7]은 비슷하여 따로 비교하는 과정을 거친다.

  4. 알고리즘이 불완전하기 때문에 무슨 숫자인지 모를경우 사람에게 직접 묻는 방법을 사용한다.

대회 당시 급하게 짜다보니 코드가 많이 더럽다.
